Политика конфиденциальности

Редакция от 16 октября 2026

Эта политика описывает, как дополнение «Конструктор анкет» для Google Docs (далее «дополнение») получает доступ к данным пользователей Google, использует, хранит и передает их.

Какие данные получает дополнение

  • Содержимое документа Google Docs, в котором пользователь открыл панель дополнения: текст, структура (абзацы, списки, таблицы, стили) и сведения о вставленных картинках (размер, формат). Доступ дается разрешением documents.currentonly и касается только этого документа.
  • Положение курсора в документе: чтобы показать настройки вопроса, в котором стоит курсор.
  • Адрес электронной почты пользователя (разрешение userinfo.email): только чтобы проверить, есть ли у него доступ к дополнению. Адрес не сохраняется и никуда не передается.
  • Разрешение script.container.ui нужно, чтобы показать панель справа от документа. Оно не дает доступа к данным.

Дополнение не получает доступа к другим документам, Google Диску, письмам, контактам и остальным данным профиля.

Как данные используются

Только для работы панели: чтобы проверить анкету, показать подсказки и ошибки, а также изменить документ по действию пользователя (вставить вопрос, перенумеровать вопросы, добавить условие). Дополнение не меняет документ без действия пользователя.

Где данные хранятся

У дополнения нет своих серверов и баз данных. Его код выполняется в Google Apps Script в аккаунте пользователя. Единственное, что дополнение сохраняет: в свойствах самого документа хранятся тексты вариантов ответа, на которые ссылаются условия анкеты, чтобы замечать, если после правки условие стало указывать на другой ответ. Эти данные остаются внутри документа и удаляются вместе с ним.

Передача данных

Дополнение никому не передает данные пользователей, включая разработчика. В нем нет аналитики, рекламы, файлов cookie и запросов к внешним сервисам.

Google API Services User Data Policy

Использование и передача дополнением информации, полученной из API Google, соответствуют Google API Services User Data Policy, включая требования Limited Use.

Как отозвать доступ

Удалите дополнение: в Google Docs Расширения → Дополнения → Управление дополнениями. Доступ также можно отозвать в аккаунте Google: Безопасность → Сторонние приложения и сервисы.

Privacy Policy

Last updated October 16, 2026

This policy describes how the Konstruktor anket (Questionnaire Builder) add-on for Google Docs (the "add-on") accesses, uses, stores and shares Google user data.

Data the add-on accesses

  • The content of the Google Docs document in which the user opens the add-on: text, structure (paragraphs, lists, tables, styles) and basic image information (size, format). Access is granted by the documents.currentonly scope and is limited to that document.
  • The cursor position in the document, to show settings for the question at the cursor.
  • The user's email address (the userinfo.email scope), only to check whether the user has access to the add-on. The address is not stored or shared.
  • The script.container.ui scope is used only to display the sidebar. It grants no access to data.

The add-on does not access other documents, Google Drive, email messages, contacts or other profile data.

How data is used

Only to provide the sidebar features: checking the questionnaire, showing hints and errors, and changing the document when the user asks (inserting a question, renumbering questions, adding a condition). The add-on does not change the document without a user action.

Where data is stored

The add-on has no servers or databases. Its code runs in Google Apps Script in the user's account. The only data it saves is stored in the document's own properties: the texts of answer options referenced by the questionnaire's conditions, used to detect when an edit makes a condition point to a different answer. This data stays inside the document and is deleted with it.

Sharing

The add-on does not share user data with anyone, including the developer. It has no analytics, advertising, cookies or requests to external services.

Google API Services User Data Policy

The add-on's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Remove the add-on in Google Docs: Extensions → Add-ons → Manage add-ons, or revoke access in your Google Account under Security → Third-party apps & services.

Changes and contact

The add-on is developed by Savva Strakhov. If this policy changes, the date above is updated. Questions about data: savva.strahov@gmail.com.
